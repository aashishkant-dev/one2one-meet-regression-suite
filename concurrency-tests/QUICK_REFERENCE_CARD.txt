 🎯 PRIORITY LEVELS (What These Mean)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  🔴 CRITICAL
  └─ MUST PASS before going live. If this fails = don't release!
     (Examples: TC-CC-001, TC-CR-005, TC-CE-006)

  🟠 HIGH
  └─ Very important. Blocking if failed. Needs fixing before release.
     (Examples: TC-CC-003, TC-CR-001)

  🟡 MEDIUM
  └─ Should pass but not blocking. Fix in next release if failed.
     (Examples: TC-CR-006)

BOOKING RACES (TC-CC-001 to 009):
  "When two people try to book the same slot at the exact same time..."

  What we want: Exactly one person gets it, other gets a clear message
  What would be bad: Both think they booked it (double-booking!) 😱


SESSION RACES (TC-CR-001 to 007):
  "When the same person does two opposing actions simultaneously..."

  What we want: One action wins, they see consistent results on all devices
  What would be bad: One device says "Accepted", other says "Rejected" 🤯


EVENT SETUP RACES (TC-CE-001 to 006):
  "When organizers edit event settings at the exact same time..."

  What we want: Event ends up in one clean state, no data corruption
  What would be bad: Event settings confused, meetings disappear 😱

BEFORE TESTING:
  ☐ Generate Excel: python generate_test_report.py
  ☐ Open: Concurrency_Test_Report.xlsx
  ☐ Fill in: Date, Tester Name, Environment (in Test Results sheet)

DURING TESTING:
  ☐ Run: .\run-tests.ps1 or npm test
  ☐ Keep Excel open on your screen
  ☐ As each test completes, immediately fill in the row:
     - Status: Pass/Fail/Not Tested
     - Actual Result: What you observed
     - Comments: Any notes or issues
  ☐ Don't wait to fill in later - do it while fresh in your mind!

AFTER TESTING:
  ☐ Check Summary sheet - your pass rate
  ☐ Find all "Fail" results
  ☐ Review and understand what went wrong
  ☐ Save file as: Concurrency_Results_[Date]_[YourName].xlsx
  ☐ Share with team

RELEASE DECISION:
  ☐ Look at Summary: Pass Rate
  ☐ Check Critical tests: Any failures? If yes → DON'T RELEASE
  ☐ Check High tests: Any failures? If yes → needs fixing
  ☐ If all tests pass → ready to release! 🎉
